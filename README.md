# Python Pizza Ordering System

## Overview
This is a command-line Python application that simulates a pizza ordering system. It allows users to select pizza size, add toppings, and automatically calculates the total price with discount logic.

## Features
- Select pizza size (Small, Medium, Large)
- Add pepperoni and extra cheese
- Automatic price calculation
- $5 discount when both pepperoni and extra cheese are selected
- Tracks total number of orders and total spending

## Technologies Used
- Python

## How to Run
1. Open terminal
2. Navigate to the project folder
3. Run:
   python pizza_order.py
